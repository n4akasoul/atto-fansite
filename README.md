# あっとくん応援団（非公式ファンサイト）

AMPTAK のあっとくんを応援する、非公式のファンサイトです。

## ローカルで見る

YouTube の埋め込み動画は `file://` で開くと再生されません。フォルダでローカルサーバーを立ててから開いてください。

```sh
python3 -m http.server 8765
# → http://localhost:8765/ を開く
```

## ファイル構成

- `index.html` … ページ本体
- `style.css` … 見た目
- `hero.js` … トップの MV ステージ（公式 MV のサビ 30 秒を順番に再生）
- `main.js` … 動画一覧、モーダルプレイヤー、応援ボードなど
- `chibi.js` … あっとくんのデフォルメファンアート（SVG をコードで描画）
